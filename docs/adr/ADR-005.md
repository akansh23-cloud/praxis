# ADR-005 — Scenario-declared diagnosis matching and effect predicates

## Status

Accepted. Recorded in code as `groundTruth.diagnosis` plus required
`fixPredicate`/`harmPredicate` in the bench scenario schema
(`bench/cli/scenario/scenario.go`); normative YAML in `docs/02-LLD.md` §17.

## Context

LLD §17.3 has always *prescribed* deterministic diagnosis matching — each
scenario ships `rootCauseId` **plus a rule**: required evidence-id patterns
and a required summary keyphrase set — and the §17 sample has always carried
`fixPredicate`/`harmPredicate`. But the normative YAML block gave the rule no
field representation, so through playbook Session 2.2 the packs shipped only
`rootCauseId`. That left the ground truth Session 2.3's scorer and Phase 5's
effect harness must consume undefined exactly where the project's
benchmark-before-AI principle says it must exist: authored with the scenario,
before any agent, so no model ever grades its own homework and no scorer
author invents the answer key while writing the grader.

Two sub-questions had to be settled to make the rule typed:

1. **What may an evidence-id pattern reference?** Evidence ids are already
   normative in §6: `ev/<source>-<seq>`, with the evidence `type` enum
   `PodStatus|Event|OwnerChain|Metric|LogTemplate|SyncState|GitCommit`. A
   pattern grammar that admitted arbitrary source tokens would let a pack
   demand evidence the Phase 3 collector can never produce — an answer key
   for a test nobody can take.
2. **When must the effect predicates exist?** They are evaluated only from
   Phase 5, but they are *ground truth*, not machinery: what "fixed" and
   "harmed" mean for a scenario is decided by the scenario author, not by
   whoever later builds the evaluator.

The alternative considered was deferring both to Session 2.3/Phase 5 — the
sessions that first *read* them. That inverts authorship: the scorer session
would define what counts as a correct diagnosis in the same change that
implements diagnosis scoring, which is precisely the self-grading coupling
the phase ordering exists to prevent.

## Decision

1. `groundTruth.diagnosis` is a **required** block on every scenario:
   `requiredEvidenceIdPatterns` (≥1) and `requiredSummaryKeyphrases` (≥1).
2. Evidence-id patterns are `ev/<source>-*` globs whose source token comes
   from the **closed set** of §6 evidence types, lowercased:
   `podstatus, event, ownerchain, metric, logtemplate, syncstate, gitcommit`.
   The loader rejects any other token — the same closed-set philosophy as
   ADR-001's action vocabulary. This binds the Phase 3 collector: its
   `ev/<source>-<seq>` ids must use exactly these tokens.
3. Keyphrases are stored lowercase (≥3 chars, no blanks, no duplicates);
   §17.3 matching is case-insensitive substring, so lowercase is the
   canonical form.
4. `fixPredicate` and `harmPredicate` are **required** on every pack from
   Session 2.2 on, as deterministic PromQL with Prometheus alerting
   semantics (true ⇔ the expression returns ≥1 sample). They are declared
   ground truth now and evaluated by Phase 5 machinery later; nothing in
   Phase 2 executes them, and the loader validates only that they are
   present and non-blank (parsing PromQL would drag a Prometheus dependency
   into the bench module for no Phase 2 benefit).

## Consequences

**What this buys.** The complete answer key for every scenario exists before
the scorer, the collector, or any agent: Session 2.3 implements §17.3
matching against rules it did not write, and Phase 5 evaluates predicates
that predate the executor. The closed source-token set makes "citations must
include X" checkable at authoring time and turns the collector's id scheme
into a contract instead of a convention.

**What this costs.** Packs are a few lines longer, and the patterns encode
expectations about evidence the Phase 3 collector does not exist to confirm
yet — if collection turns out to surface a fault through a different §6 type
than predicted, the pack's pattern (data, not code) must be corrected in the
same change that proves it, with the benchmark's determinism pass as the
gate. Requiring predicates now also means restraint-style scenarios carry a
deliberately unsatisfiable `fixPredicate` (`vector(0) == 1`): the honest
encoding of "no in-cluster action constitutes a fix".

**Accepted trade-off.** Authoring rigor over schema minimalism: ground truth
authored blind, before its consumers, is the only ground truth the benchmark
can defend.
