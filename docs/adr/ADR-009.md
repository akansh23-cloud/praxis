# ADR-009 — Citation failure is refused before a plan exists, and rejected if one does

## Status

Accepted. Recorded in code as `validate.BundleCitationValidator` and
`validate.UnresolvedCitations` (`internal/validate/citations.go`), the
bundle-loading `handleValidating` of
`internal/controller/remediationplan_controller.go`, the
`praxis.dev/analysis-rejected` annotation and `AnalysisAccepted` condition
(`api/v1alpha1`), the `praxis_plans_total{phase,reason}` counter
(`internal/controller/metrics.go`), and the agent-side refusal in
`internal/agents/llm` and `bench/cli/agentrun`. Proven by
`internal/validate/citations_test.go`, the citation specs in
`internal/controller/remediationplan_controller_test.go`, the annotation
spec in `incident_controller_test.go`, and the agent and harness tests.

## Context

FR-P3-04 makes an unresolved citation a first-class outcome: `Rejected`,
reason `CitationInvalid`, metric incremented. Playbook Session 3.3 offers
two lifecycles for a plan whose hypothesis cites evidence the bundle does
not hold — create it only to be rejected, or never create it and annotate
the Incident — and asks for one to be chosen, justified, and counted by
`praxis_plans_total{reason="CitationInvalid"}` either way.

Two facts shaped the choice. First, the benchmark runs no controller: the
harness files the Incident, drives the Agent in-process and observes the
cluster. A "create, then let the controller reject" lifecycle would leave
a plan Pending forever in a bench cluster and would credit its
hypotheses' citations to the diagnosis score, because §17.3 matching is a
glob over ids, not a resolution. Second, the Phase 1 stub validator passed
every plan; Phase 1 fixtures set a hash on the Incident by hand and
persisted no bundle, so any real validator must decide what "no bundle"
means.

## Decision

1. **Validation is one deterministic function, applied at both ends.**
   `validate.UnresolvedCitations` is set membership of every cited id in
   the exact bundle analyzed. Nothing about an id's shape earns trust; an
   unresolved citation fails the whole hypothesis; nothing is silently
   dropped or repaired; no model is ever asked to validate its own
   citations.
2. **Agent side: refused, never created.** The LLM agent runs the
   validator over its own output and returns `agents.CitationError`
   instead of hypotheses; the harness runs the validator again over
   whatever any agent returns (an agent that lies about validating is
   caught), creates no plan, and writes
   `praxis.dev/analysis-rejected: "CitationInvalid: <ids>"` on the
   Incident. The benchmark records the run as `AnalysisRejected` with
   reason `CitationInvalid`: diagnosis top-k false (the hypotheses are kept
   only for forensics), restraint incorrect, no plan metrics. The same
   annotation carries `SchemaInvalid` when the planner's output failed the
   CRD schema on its single retry (FR-P3-05).
3. **Controller side: rejected, always.** Every persisted plan, from any
   producer, is checked against the bundle its `evidenceBundleHash`
   names: the Incident's `evidenceBundleRef` ConfigMap must exist and its
   bytes must hash to that value (else `EvidenceValid=False`,
   `EvidenceMismatch`), and every citation must resolve (else
   `CitationsResolved=False`, `CitationInvalid`, phase `Rejected`). An
   Incident with a hash but no persisted bundle cannot resolve anything
   and is rejected the same way — "cannot verify" is never "verified".
4. **The metric counts both.** `praxis_plans_total{phase,reason}` counts
   every plan phase entry with its decisive reason, so
   `{phase="Rejected",reason="CitationInvalid"}` counts controller
   rejections; the Incident controller mirrors the annotation into
   `AnalysisAccepted=False` and counts it once under
   `{phase="NotCreated",reason="CitationInvalid"}` (or `SchemaInvalid`).
   `NotCreated` is a metric label, deliberately not a `PlanPhase`.

## Consequences

**What this buys.** No object is ever persisted whose claims are known to
be unsupported, so the approval surface never shows a hallucinated
citation; the failure is nonetheless a cluster-visible, countable outcome
on the Incident; the controller guard covers producers that skip the
agent-side check; and the benchmark scores a citation failure as a
failure, not as a pattern-matched diagnosis hit.

**What this changed.** Phase 1 fixtures that set a hash without a bundle
now persist a real bundle (envtest helper, Chainsaw `bundle.json`, the
demo scripts collect for real) and cite an id it holds; the sample plan's
citations name what the demo bundle actually contains.

**What it costs.** Two validation sites to keep identical — mitigated by
sharing one function. An analysis refused agent-side leaves no plan to
inspect; the annotation carries the unresolved ids instead.
